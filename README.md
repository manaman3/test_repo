# 🎓 English Vocabulary Trainer Bot for MAX

Бот в мессенджере **MAX** для изучения английской лексики.
Помогает учить слова, проверять перевод (текстом и голосом) и проверять
правильность составления предложений через LLM.

## ✨ Возможности

- 📖 **Учить слова** — карточки по темам: слово, транскрипция, перевод, пример
- 🔁 **Проверка слов** — ученик отвечает переводом текстом или голосом
- ✍️ **Составить предложение** — проверка грамматики через LLM
- 🎤 **Распознавание речи** — STT через `faster-whisper` (модель `small.en`)
- 🧠 **AI-обратная связь** — исправление, ошибки, оценка, альтернативы
- 💬 **Текстовый и голосовой ввод** — на выбор ученика

## 🏗 Архитектура

```
┌──────────────┐      HTTPS       ┌──────────────┐
│   MAX        │ ───────────────▶ │   Nginx      │
│  (Bot API)   │ ◀─────────────── │  :80 / :443  │
└──────────────┘                  └──────┬───────┘
                                         │ HTTP
                                         ▼
                                  ┌──────────────┐
                                  │     bot      │
                                  │   :8080      │
                                  │  (Python)    │
                                  └──────┬───────┘
                                         │
                       ┌─────────────────┼─────────────────┐
                       ▼                 ▼                 ▼
                 ┌──────────┐     ┌──────────┐     ┌──────────┐
                 │    LLM   │     │  Whisper │     │ words.   │
                 │          │     │  (STT)   │     │  json    │
                 └──────────┘     └──────────┘     └──────────┘
```

**Компоненты:**

- **MAX Bot API** — источник событий (`message_created`, `message_callback`, `bot_started`).
- **Nginx** — приём HTTPS-запросов и проксирование на бота.
- **bot** — Python-приложение: обработка команд, режимы, работа с LLM и STT.
- **LLM** — внешний LLM-провайдер (проверка предложений).
- **faster-whisper** — локальное распознавание речи (модель `small.en`).
- **words.json** — локальный словарь (100 слов).

## 🎯 Основной пользовательский сценарий

Один сквозной цикл от нового слова до проверки речи:

1. Ученик открывает бота в MAX и отправляет `/start`.
2. Выбирает режим `/learn` — получает слово, транскрипцию, перевод, пример.
3. Переходит в `/practice` — отвечает переводом (текстом или голосом).
4. Отправляет голосовое — бот распознаёт через Whisper и проверяет.
5. Переходит в `/sentence` — придумывает предложение с заданным словом.
6. Отправляет текстом или голосом — бот проверяет через LLM.
7. Получает разбор: исправление, ошибки, оценку, рекомендации.

## 💾 Настройка Swap

Нужен для работы faster-whisper и Docker на слабых VPS.

```bash
# 1. Создание swap-файла на 2 ГБ
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile

# 2. Форматирование и активация
sudo mkswap /swapfile
sudo swapon /swapfile

# 3. Автозапуск при перезагрузке
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# 4. Оптимизация под Docker
sudo sysctl vm.swappiness=10
echo 'vm.swappiness=10' | sudo tee -a /etc/sysctl.conf

# 5. Проверка
free -h
```


## 🗂 Работа с данными

**Что хранится:**

- `words.json` — словарь из 100 слов (слово, транскрипция, перевод, пример).
- Состояние пользователя — in-memory, в объекте `Voice` (список `users`, `users_sent`, словарь `words`).
- Идентификатор пользователя — только `user_id` из MAX.

**Что НЕ хранится:**

- Голосовые сообщения не сохраняются — обрабатываются в памяти (`BytesIO`) и удаляются после распознавания.
- Персональные данные (имя, телефон, email) не собираются.
- История проверок не сохраняется.

**Безопасность:**

- Токены и API-ключи — только через переменные окружения.
- `.env` не коммитится в репозиторий.
- Секреты недоступны в образе.

## ⚠️ Известные ограничения

- **STT локальный** — модель `small.en` загружается в память (~500 МБ RAM), требует swap на слабых VPS.
- **Нет SRS** — интервальное повторение не реализовано.
- **Нет истории** — проверки и слова не сохраняются между сессиями.
- **Модель `small.en`** может ошибаться при сильном акценте.
- **Лимиты LLM** — при исчерпании квоты проверка предложений недоступна.
- **Размер образа** ~2 ГБ из-за `faster-whisper`.

## 🩺 Решение проблем

### Не хватает места на диске

```bash
docker system df
docker system prune -a
docker builder prune -a

# Если используется containerd
sudo systemctl stop docker docker.socket containerd
sudo rm -rf /var/lib/containerd/io.containerd.content.v1.content/*
sudo rm -rf /var/lib/containerd/io.containerd.snapshotter.v1.overlayfs/*
sudo rm -rf /var/lib/docker/*
sudo systemctl start containerd docker
```

### Ошибка 502 Bad Gateway в nginx

Nginx не может достучаться до бота. Проверьте:

```bash
docker compose ps
docker compose logs bot --tail 100
docker compose exec nginx wget -qO- http://bot:8080/ || echo fail
```

В `nginx.conf` upstream должен ссылаться на **имя сервиса**:

```nginx
location /webhook {
    proxy_pass http://bot:8080/;
}
```

А не на статический IP — он меняется после пересборки.

### Ошибка SSL при запросе к российскому API

Убедитесь, что установлены сертификаты Минцифры и контейнер их видит.
При необходимости — пересоберите образ.

### `json_schema` не поддерживается

Если LLM возвращает поля с другими именами (`grade` вместо `score`),
используется нормализация ответа — см. `ai_check.py`.

### `curl` к API MAX не проходит

Проверьте, что используется `-k` (если CA не доверенный) и что в
`Authorization` нет лишних пробелов.
